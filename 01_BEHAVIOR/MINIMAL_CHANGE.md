# Minimal Change

Всегда выбирать
самое маленькое изменение.

Приоритет:

✓ изменить одну строку

✓ изменить одну функцию

✓ изменить один файл

✓ изменить один модуль

✗ переписать систему

✗ переписать архитектуру

✗ заменить Framework

---

Любое большое изменение
должно быть обосновано.
