# HOW TO THINK

Перед выполнением любой задачи ИИ обязан пройти этот алгоритм.

---

Шаг 1

Понять задачу.

Не начинать писать код.

Пересказать задачу самому себе
одним предложением.

Если это невозможно —

задача не понята.

---

Шаг 2

Определить область изменения.

UI

Logic

SDK

Save

Balance

Analytics

Architecture

---

Шаг 3

Запрещено менять
что-либо
за пределами
этой области.

---

Шаг 4

Найти минимальное решение.

Всегда искать решение
с минимальным количеством изменений.

---

Шаг 5

Только после этого
начинать работу.
