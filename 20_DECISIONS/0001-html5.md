# 0001 — Использовать HTML5

**Дата:** 2026-07-14
**Статус:** Принято

## Контекст

Нужно выбрать платформу для казуальных игр студии. Аудитория — Яндекс Игры, мобильные браузеры, десктоп. Цикл разработки одной игры — 7-10 дней.

## Решение

Использовать **HTML5** как основную платформу для всех игр студии.

## Альтернативы

- **Unity** — слишком тяжёлый для 7-дневного цикла, экспорт занимает время, требует установки
- **Unreal** — overkill для казуальных 2D игр
- **Construct 3** — ограниченный, ИИ плохо с ним работает
- **Ren'Py** — для визуальных новелл, не для merge/clicker
- **Godot** — экспорт в Web OK, но ИИ хуже пишет GDScript, чем TypeScript

## Последствия

✅ ИИ лучше всего пишет HTML/JS/TS код (наибольший объём тренировочных данных)
✅ Минимальный размер билда (< 5 МБ для Яндекс)
✅ Мгновенный запуск в браузере
✅ Простая публикация (один HTML файл)
✅ Дешёвая разработка (бесплатные инструменты)
✅ Хорошо работает на мобильных

❌ Ограниченная производительность (3D, шейдеры)
❌ Не подходит для high-end графики

## Когда пересмотреть

- Если студия захочет делать 3D игры
- Если ИИ-модели перестанут хорошо писать TypeScript
- Если Яндекс Игры прекратят поддержку HTML5
