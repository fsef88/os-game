# 0002 — Использовать Vite как бандлер

**Дата:** 2026-07-14
**Статус:** Принято

## Контекст

Нужен инструмент сборки для TypeScript-проектов студии. Требования: быстрый dev-server, простая продакшен-сборка, поддержка ESM.

## Решение

Использовать **Vite** как основной бандлер.

## Альтернативы

- **Webpack** — медленный, сложная конфигурация
- **Parcel** — zero-config, но медленнее Vite
- **esbuild** — быстрый, но нет dev-server
- **tsc** (нативный) — нет HMR, нет сборки
- **Rollup** — для библиотек, не для приложений
- **Без бандлера** (отдельные .ts файлы) — неудобно для production

## Последствия

✅ Мгновенный cold start (< 1 сек)
✅ HMR (Hot Module Replacement) — изменения видны сразу
✅ Простая конфигурация (5 строк)
✅ ESM из коробки
✅ Поддержка TypeScript без настройки
✅ Production build с минификацией
✅ assetsInlineLimit для встраивания ресурсов в HTML

❌ Молодой проект (но уже стабильный)
❌ Иногда проблемы с редкими плагинами

## Когда пересмотреть

- Если появится бандлер с заметно лучшей производительностью
- Если Vite перестанет поддерживаться
- Если студия захочет SSR
