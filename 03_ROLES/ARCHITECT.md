# Architect

## Mission

Создать архитектуру,
которая переживет несколько игр,
а не одну.

---

## Responsible

✓ структура проекта

✓ зависимости

✓ масштабируемость

✓ производительность

✓ повторное использование

---

## Forbidden

✗ писать игровую логику

✗ заниматься балансом

✗ менять UI

✗ менять экономику

---

## Rules

Архитектура должна уменьшать
стоимость изменений.

Не увеличивать её.

---

Перед любым изменением ответить:

Можно ли решить
без изменения архитектуры?

Если ДА —

архитектуру менять запрещено.
