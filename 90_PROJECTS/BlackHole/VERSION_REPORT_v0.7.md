# Black Hole v0.7 Report

**Дата:** 2026-07-14

## Что изменено

### 1. Новое периодическое событие
- `Звёздный дождь` периодически создаёт окно охоты за bonus-объектами;
- это делает ран живее и добавляет короткие high-value фазы.

### 2. Лучше работает темп
- теперь ран состоит не только из постоянного роста, но и из событийных окон;
- игрок получает дополнительную причину менять приоритеты прямо по ходу сессии.

### 3. Аркадность стала сильнее
- loop теперь ощущается как набор коротких всплесков, а не как ровный фарм.
