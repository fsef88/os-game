# CHANGELOG

## v2.0.0 — 2026-07-14
- исправлен белый экран в Arena viewer: release `index.html` теперь standalone-файл с inline CSS/JS, без внешнего module-загрузчика;
- сохранён full mobile-game visual rework, но упаковка стала пригодной для мгновенного предпросмотра через `present_file`;
- production assets изображений оставлены рядом в `assets/`, CSS внутри HTML переписан на корректные локальные пути;
- версия поднята до `2.0.0` как первый стабильный standalone mobile-game style release.

## v1.9.0 — 2026-07-14
- выполнена полная переработка визуальной части под стиль дорогого mobile game screenshot;
- убраны hero/dashboard/bottom-панели из основного экрана: игровое поле теперь занимает почти весь экран;
- оставлен минимальный top HUD внутри игрового мира: жизни, счёт, размер и комбо;
- добавлена большая кинематографичная city-map сцена с дорогами, зданиями, парками, деревьями, городскими огнями, bloom/glow и parallax/dust слоями;
- чёрная дыра стала главным фокусом: усилены синее свечение, вихрь, орбитальные кольца, пространственное искажение и частицы;
- объекты получили более juicy mobile-game подачу: сверкающие монеты, объёмные коробки, glowing magnet pickup, аптечка-бонус;
- кнопки сведены к маленьким круглым игровым controls с glassmorphism/blur.

## v1.8.0 — 2026-07-14
- выполнен mobile combat HUD pass: добавлен вертикальный skill stack прямо внутри арены;
- кнопка `Сингулярный рывок` продублирована как игровой skill-orb поверх сцены и остаётся интерактивной;
- добавлен in-arena minimap/radar с игроком, автобусом, опасностями и бонусными объектами;
- добавлен objective rail с текущей целью роста, районом и прогрессом до следующей стадии;
- при тяжёлом столкновении теперь появляется красный burst-VFX вокруг чёрной дыры;
- сцена стала ближе к референсным mobile screenshots: игровые элементы читаются как внутриигровой HUD, а не как внешняя панель.

## v1.7.0 — 2026-07-14
