# CHANGELOG

## v0.5.0 — 2026-07-14
- добавлен run timer в HUD;

- усилены danger-signal и combo-rush подача;

- добавлен district banner при переходе между районами;

- ядро рывка мгновенно сбрасывает cooldown способности;
- сердце восстанавливает жизнь;
- bonus-объекты визуально выделены на сцене;
- standalone и dev-версия синхронизированы под новый reward layer.
