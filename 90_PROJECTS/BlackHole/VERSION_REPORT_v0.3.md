# Black Hole v0.3 Report

**Дата:** 2026-07-14

## Что изменено

### 1. Новый reward layer
- масса больше не единственная ценность;
- добавлен отдельный счёт;
- сильнее ощущается reward stacking.

### 2. Новые типы объектов
- `Звезда` — даёт бонус к очкам;
- `Сердце` — восстанавливает жизнь;
- `Ядро рывка` — мгновенно сбрасывает cooldown рывка.

### 3. Визуальная читаемость
- bonus-объекты выделены сильнее;
- у автобуса и специальных pickup-объектов более явное значение на сцене.
