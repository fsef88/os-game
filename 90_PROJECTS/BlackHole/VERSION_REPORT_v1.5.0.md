# Black Hole v1.5.0 Report

**Дата:** 2026-07-14

## Что изменено

### 1. District-art pass
- у каждого района теперь свой отдельный фон;
- смена района читается не только цветом, но и характером пространства.

### 2. Release pipeline улучшен
- production build выпускает изображения как отдельные asset-файлы;
- release-сборка стала ближе к реальной поставке проекта.

### 3. Сцена стала ближе к game concept
- background, арена и объекты теперь визуально меньше спорят между собой;
- стало проще воспринимать происходящее как игру, а не как оформленный макет.
