# OPEN ME FIRST

Если хочешь просто открыть прототип двойным кликом, открой:

- `OPEN_THIS_IN_BROWSER.html`

Если хочешь смотреть dev-проект:

```bash
cd src
npm install
npm run dev
```

Важно:
- `src/index.html` — это исходник под Vite/TypeScript;
- для прямого открытия без dev-server используй standalone HTML.
