# CHANGELOG

## v1.0.0 — 2026-07-14
- доведён вертикальный срез `Alchemy Lab` до автономного playable-прототипа;
- весь игровой UI и названия предметов переведены на русский;
- добавлены бонус дня, поручения алхимика, уровень лаборатории и особые контракты;
- улучшены early rewards и структура первой сессии;
- standalone HTML и dev-версия синхронизированы.
