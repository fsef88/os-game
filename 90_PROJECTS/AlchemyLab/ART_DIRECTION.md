# ART DIRECTION

**Версия:** 1.0.0

## Стиль

Мистическая, но уютная лаборатория. Не мрачное фэнтези, а тёплая casual-магия: колбы, светящиеся травы, карточки заказов, мягкий glow.


## Визуальный принцип

Каждый следующий tier должен выглядеть:
- светлее;
- ценнее;
- магичнее;
- заметно отличаться от прошлого.

## UI

- крупные карточки;
- мягкие тени;
- чёткая иерархия: order → board → journal;
- минимум мелкого текста.
