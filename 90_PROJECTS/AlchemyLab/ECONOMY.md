# ECONOMY

**Версия:** 0.2.0

## Валюта

### Essence

**Назначение:** основная валюта лаборатории  
**Источники:** выполнение заказов  
**Тратится на:** новые клетки, улучшение катализатора

## Прогрессия

### Тип: hybrid step + merge value

- core value растёт через tier предмета;
- reward растёт через заказы;
- multiplier растёт через catalyst.

## Источники дохода

| Источник | Сумма | Условие |
|---|---|---|
| Order tier 1 | 12+ | выполнить заказ на Glow Herb |
| Order tier 2 | 28+ | выполнить заказ на Moon Bloom |
| Order tier 3 | 65+ | выполнить заказ на Aether Crystal |
| Order tier 4 | 150+ | выполнить заказ на Sun Elixir |

## Sink'и

| Действие | Стоимость | Зачем |
|---|---|---|
| Unlock cell | 20 / 40 / 70 | увеличить пространство на столе |
| Catalyst upgrade | 25 * 1.8^level | увеличить reward multiplier |

## Основной экономический смысл

Игрок не зарабатывает essence напрямую кликом. Сначала он создаёт value через merge, и только потом превращает его в reward через order fulfillment.

Это делает loop интереснее clicker-экономики.
