# OPEN ME FIRST

Если хочешь просто **открыть игру в браузере двойным кликом**, открой:

- `OPEN_THIS_IN_BROWSER.html`

Если хочешь смотреть исходный проект как разработчик:

```bash
cd src
npm install
npm run dev
```

Важно:
- `src/index.html` — это исходник для Vite/TypeScript;
- его **не надо** открывать напрямую через `file:///.../src/index.html`;
- для прямого открытия без сборки используй `OPEN_THIS_IN_BROWSER.html`.
