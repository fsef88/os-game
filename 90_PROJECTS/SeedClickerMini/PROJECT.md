# PROJECT

**Название:** Seed Clicker Mini  
**Версия:** 0.1.0  
**Дата старта:** 2026-07-14

## Elevator Pitch

Микро-кликер про выращивание богатства из одного семечка: тапай, усиливай тап, запускай авто-рост и дойди до золотого урожая.

## Core Loop

```
Тап по семечку
  ↓
Получить монеты
  ↓
Купить улучшение тапа / авто-доход
  ↓
Расти быстрее
  ↓
Повторить
```

## Meta Loop

```
Сессия
  ↓
Усиление тапа и авто-дохода
  ↓
Достижение нового доходного milestone
  ↓
Более быстрый рост следующей сессии
```

## Главная цель игрока

За короткую сессию пройти путь от 1 монеты за тап до устойчивого автоматического роста и почувствовать ускорение прогресса.

## MVP

### Что входит
- тап по центральной кнопке;
- 2 вида апгрейдов;
- сохранение прогресса;
- базовый HUD;
- playable flow за 1-3 минуты.

### Что не входит
- реклама;
- сложная экономика;
- многоэкранный UI;
- глубокий liveops.
