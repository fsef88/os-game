# ANALYTICS

**Версия:** 0.1.0

## Основные события

- game_start
- game_ready
- session_start
- session_end
- tap_seed
- buy_tap_upgrade
- buy_auto_income

## KPI пилота

| Метрика | Цель |
|---|---|
| First action time | < 5 sec |
| First upgrade time | < 20 sec |
| First auto-income time | < 45 sec |
| Session length | 1-3 min |

## Зачем аналитика в пилоте

Даже микро-проект должен показать, что шаблон умеет не только рендерить UI, но и логировать ключевые действия.
