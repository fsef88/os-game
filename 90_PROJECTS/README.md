## Как использовать

1. Скопировать `TEMPLATE/` в новую папку проекта
2. Заполнить документы проекта
3. Перейти в `src/`
4. Выполнить `npm install && npm run dev`
5. Дальше идти по playbook'у жанра

## Правило

В `90_PROJECTS/` лежат только:
- шаблон проекта;
- реальные проекты;
- их локальная документация.

Общая студийная документация сюда не складывается.
