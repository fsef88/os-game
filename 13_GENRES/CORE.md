## Что такое жанр

Жанр отвечает на вопрос: **что игрок делает руками и глазами большую часть времени**.

Жанр — это не тема и не сеттинг.
- Merge Farm и Merge Space — один жанр
- Clicker Bakery и Clicker Factory — один жанр

## Как выбирать жанр

Проверить 5 критериев:

1. Понятен ли core loop за 10 секунд?
2. Можно ли сделать MVP за 7–10 дней?
3. Есть ли место для retention-механики?
4. Подходит ли под mobile browser?
5. Не требует ли backend / сложной симуляции?

## Разрешённые жанровые семейства

- Merge
- Clicker
- Idle
- Tycoon
- Puzzle / Match-like
- Incremental
- Collector / Builder

## Запрещённые жанры для этой системы

- MMO
- Multiplayer-heavy
- 3D high-end
- Hardcore strategy
- genres с тяжёлым backend

## Правило выбора

> Если жанр нельзя объяснить в 1 предложении и 1 core loop — он слишком сложен для текущего scope.
