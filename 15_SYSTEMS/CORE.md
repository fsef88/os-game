**Версия:** 1.0  
**Дата:** 2026-07-14

---

## Что такое система

System отвечает на вопрос: **как это реализовано технически**.

Примеры:
- Save System
- Economy System
- UI System
- Audio System
- Event System

## Граница ответственности

- Genre знает, какой опыт нужен
- Mechanic знает, какая логика нужна
- System знает, как это собрать в коде
- Component знает, как это выглядит в UI

## Правила хорошей системы

1. Переиспользуема
2. Не знает лишнего о жанре
3. Имеет ясный API
4. Может работать в template без переписывания
5. Не тянет лишние зависимости

## Антипаттерн

❌ Делать system, которая знает конкретный проект, жанр и экран одновременно.
