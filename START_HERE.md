3. `00_CORE/ARCHITECTURE.md` — как устроены слои
4. `01_BEHAVIOR/HOW_TO_THINK.md` — как принимать решения
5. `02_RULES/AI_RULES.md` — обязательные правила
6. `PROJECT_STATE.md` — текущее состояние системы
7. `INDEX.md` — каталог по темам

- новая игра → `BOOTSTRAP_KIT.md`
