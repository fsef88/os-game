# Documentation Rules

Документация —

часть продукта.

Не приложение.

---

Любое изменение проекта

обновляет документацию.

---

Документация
не должна
противоречить коду.

---

Документ
должен читаться
менее чем за 3 минуты.

---

Если документ
не помогает разработке —

его удалить.
