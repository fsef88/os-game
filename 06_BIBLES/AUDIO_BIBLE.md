## 1. ПРИНЦИПЫ

### Звук — половина опыта

Без звука игра ощущается "мёртвой". С плохим звуком — дешёвой.

### Главное правило

> Звук должен подкреплять действие, не раздражать.

---

## 2. КАНАЛЫ

### Master
- Общая громкость (0-1)

### SFX (звуковые эффекты)
- UI clicks
- Merge
- Spawn
- Coins
- Errors
- Success

### Music (фоновая музыка)
- Главное меню (опционально)
- В игре (тихо)
- Событие (громче, энергичнее)

### Voice (голос)
- Не используется в casual

## 3. КОГДА ИГРАТЬ

### Всегда
✅ Click на кнопку  
✅ Получена монета  
✅ Merge  
✅ Уровень вверх  
✅ Достижение  
✅ Новая клетка  
✅ Открыт питомец

### Иногда
🎵 Кейс открывается (один раз, не зацикленно)  
🎵 Событие (не чаще 1 раза в день)  
🎵 Daily reward

### Никогда
❌ Первые 3 секунды игры  
❌ Дольше 3 сек подряд  
❌ При таймере ожидания  
❌ В модалке подтверждения  
❌ При ошибке сети (игрок и так нервничает)

## 4. КОНКРЕТНЫЕ ЗВУКИ (из Merge Farm)

### Звук монеты
- Короткий (200-400ms)
- "Цок-цок"
- Повторять при каждом получении, но тише если подряд

### Звук merge
- "Пуф" + небольшой рост ноты
- Длительность 300-500ms

### Звук нового предмета
- Восходящая нота
- "Дзынь!"
- Длительность 500-700ms

### Звук ошибки
- "Бум" (низкий)
- Длительность 200-300ms

### Звук level up
- Короткая фанфара
- Длительность 1000-1500ms

### Звук reward
- Восходящая мелодия
- Длительность 700-1000ms

## 5. ФОНОВАЯ МУЗЫКА

### Главное правило

Должна быть ТИХОЙ. Не мешать игре.

### Громкость
- music: 0.2-0.3 (фон)
- sfx: 0.5-0.7 (над фоном)
- ratio: sfx в 2 раза громче music

### Темп
- Спокойная (60-90 BPM) — для core loop
- Энергичная (100-120 BPM) — для событий
- Тишина — между сессиями

### Loop
- Бесшовный (из того же тона начинается и заканчивается)
- Длительность 2-3 минуты
- Случайный выбор из 2-3 треков (чтобы не приедалось)

### Когда НЕ играть

❌ В первые 5 секунд (игрок не ожидает)  
❌ При показе рекламы (прерывается)  
❌ При ошибке сети (напрягает)  
❌ Во время таймера ожидания (усиливает напряжение)

## 6. ОТКЛЮЧЕНИЕ

### Master toggle
Один переключатель — выключает ВСЁ.

### Раздельные toggle
- Music
- SFX
- Voice (если есть)

### Сохранение
В state:
```ts
state.audio = {
  master: 0.7,
  music: 0.3,
  sfx: 0.7,
};
```

### По умолчанию
- master: 0.7
- music: 0.3
- sfx: 0.7
- Не принуждать (можно менять)

## 7. ПРОИЗВОДСТВО

### Формат
- MP3 или OGG
- 44.1 kHz
- 16-bit
- Mono (для sfx), Stereo (для music)

### Размер
- SFX: 5-50 KB каждый
- Music: 500 KB - 2 MB каждый
- Общий: < 2 MB

### Источники
- freesound.org (CC0)
- zapsplat.com (бесплатно с указанием)
- Собственная запись
- AI-генерация (новая возможность)

### Библиотека

Хранить звуки в одном месте:
```
assets/
  audio/
    sfx/
      click.mp3
      coin.mp3
      merge.mp3
      error.mp3
    music/
      main_loop.mp3
      event.mp3
```

### Прелоад

Загружать при старте:
```ts
const audioCtx = new AudioContext();
const sounds = {
  click: loadSound('/audio/sfx/click.mp3'),
  coin: loadSound('/audio/sfx/coin.mp3'),
  // ...
};
```

### Лейзи-загрузка

Большие файлы (music) — по требованию.

## 8. ТЕСТИРОВАНИЕ

### Перед каждым релизом

- [ ] Звук включается при клике
- [ ] Звук выключается в настройках
- [ ] Музыка не мешает
- [ ] Нет щелчков / обрывов
- [ ] Громкость в разумных пределах
- [ ] Loop бесшовный
- [ ] Все звуки в наличии (нет 404)
- [ ] Задержка < 100ms

### На разных устройствах

- [ ] iPhone (safari)
- [ ] Android (chrome)
- [ ] Desktop (chrome)
- [ ] Yandex Browser

## 9. ЧАСТЫЕ ОШИБКИ

❌ Звук включается на полную при старте (пугает)  
❌ Звук в первые 3 секунды (не ожидается)  
❌ Музыка громче sfx (мешает)  
❌ Зацикленный звук (раздражает)  
❌ Разные стили звуков (непоследовательно)  
❌ Слишком много звуков одновременно (каша)  
❌ Слишком тихо (игрок не слышит)  
❌ Нет возможности отключить (модерация завернёт)
