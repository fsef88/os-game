## 1. ПРИНЦИПЫ

### Главный закон

> Игрок никогда не должен копить слишком долго.
> Каждая покупка должна ощущаться полезной.

### Частота покупок

```
Первые 10 минут   — каждые 30-60 секунд
Первый час        — каждые 2-3 минуты
Первый день       — каждые 5-10 минут
Первые 3 дня      — каждые 15-30 минут
После 3 дней      — по желанию игрока
```

Это "поток" экономики. Игрок никогда не чувствует, что деньги бесполезны.

### Что никогда не делать

- ❌ Бесполезные улучшения (например, +1% к скорости за 1000 монет)
- ❌ Слишком дорогие первые покупки (убивает онбординг)
- ❌ Слишком дешёвые поздние покупки (инфляция)
- ❌ Несколько валют без причины (путает игрока)
- ❌ Pay-to-win (нельзя купить то, что нельзя получить игрой)

## 2. ВАЛЮТЫ

### Мягкая валюта (soft)

Назначение: основной игровой ресурс.  
Источник: merge, продажа, квесты, достижения, оффлайн.  
Тратят: новые клетки, бусты, кейсы.

**Из Merge Farm:** только `coins` (одна мягкая валюта).

### Жёсткая валюта (hard)

Назначение: премиум-контент.  
Источник: rewarded ads, достижения, IAP (если есть).  
Тратят: эксклюзивные ускорения, косметика, премиум-клетки.

**Из Merge Farm:** `crystals` (жёсткая валюта, только за rewarded и достижения).

### Когда добавлять вторую валюту

Только если:
- Есть реальная необходимость (премиум-контент есть)
- Игрок не путается (разное назначение очевидно)
- Управление инфляцией в основной валюте становится невозможным

### Когда НЕ добавлять

- "Чтобы было" — нет
- "Потом пригодится" — нет
- "В других играх так" — нет

### Правило для MVP

**Одна валюта.** Это аксиома. Если думаешь, что нужна вторая — почти всегда ошибаешься.

## 3. ПРОГРЕССИЯ

### Типы прогрессии

#### A. Линейная (редко)

```ts
level_cost = base * level
```

Подходит для: уровни зданий, размер инвентаря.

#### B. Экспоненциальная (стандарт)

```ts
cost = base * Math.pow(growth, level)
```

Примеры `growth`:
- 1.1 — медленный рост (хорошо для покупок)
- 1.3 — средний (хорошо для level-up)
- 1.5 — быстрый (хорошо для late-game)
- 2.0 — агрессивный (эндгейм, prestige)

**Из Merge Farm:** новые слоты сетки = 500 → 800 → 1500 → 2500 → 5000 → 8000 → 25000 (примерно 1.5x рост).

#### C. Ступенчатая (хорошо для бустов)

```ts
if (level < 5) return base1;
if (level < 10) return base2;
return base3;
```

#### D. Прогрессия с "зубьями" (хорошо для prestige)

```ts
// каждая 5-я покупка вдвое дороже
cost = base * Math.pow(growth, level) * (level % 5 === 0 ? 2 : 1);
```

### Что выбрать

| Ситуация | Тип | growth |
|---|---|---|
| Покупка слота | экспонента | 1.5 |
| Upgrade дохода | экспонента | 1.3 |
| Открытие уровня | линейная | — |
| Буст | ступенчатая | — |
| Кейс | экспонента | 1.2 |
| Престиж | экспонента | 2.0+ |

## 4. ИНФЛЯЦИЯ

### Что это

Игрок накапливает слишком много денег, и они обесцениваются. Покупки становятся незначительными.

### Как обнаружить

- Игрок копит > 5 минут, не тратя
- Cost следующей покупки < 1% от текущего баланса
- Доход за минуту меньше стоимости базовой покупки

### Как лечить

#### A. Новые tier'ы (лучший способ)

Каждые 2-3 дня добавляется новый уровень предметов, который стоит дороже.

#### B. Скейлинг цен

```ts
// если у игрока слишком много денег, цены растут быстрее
function getAdjustedCost(base: number, playerMoney: number): number {
  if (playerMoney > base * 10) return base * 2;
  return base;
}
```

#### C. Sink'и (стоки денег)

Способы "сжечь" деньги:
- Престиж (сброс прогресса за бонус)
- Ре-roll редкого предмета
- Косметика (декор фермы)
- Улучшение питомцев
- Расширение инвентаря

#### D. Динамическая сложность

```ts
// Чем больше у игрока денег, тем реже выпадают хорошие предметы
function getRareChance(playerLevel: number): number {
  return Math.max(0.005, 0.02 - playerLevel * 0.0005);
}
```

### Лучшая комбинация

```
Новые tier'ы (раз в 2-3 дня) +
Sink'и (питомцы, коллекция) +
Динамическая редкость (поздняя игра)
```

## 5. НАГРАДЫ

### Правила хорошей награды

- ✅ Меняет состояние игры (не косметика только)
- ✅ Подкрепляет текущее действие
- ✅ Не слишком большая (не "ломает" экономику)
- ✅ Не слишком маленькая (заметна)
- ✅ Имеет визуальное/звуковое сопровождение

### Типы наград

| Тип | Когда | Размер |
|---|---|---|
| Микро | Каждый merge | +1-5 монет |
| Мезо | Каждые 3-5 минут | новая клетка, кейс |
| Макро | Квест, достижение | 100-1000 монет, буст |
| Мега | Уровень, событие | премиум-валюта, уникальный предмет |

### Связка наград (reward stacking)

Лучшие моменты — комбинация:

```
Новый овощ
+ анимация появления
+ свечение
+ звук "уровень вверх"
+ +50 монет
+ коллекция обновилась
+ следующая цель показалась
```

Это в 5 раз сильнее, чем любой слой по отдельности.

### Пустые награды (запрещено)

Награда, которая ничего не меняет — хуже, чем её отсутствие.

Примеры пустых наград:
- ❌ +5 монет при балансе 1 000 000
- ❌ +1% к доходу при балансе 1 000 000
- ❌ Уже открытый предмет в коллекции
- ❌ Буст, который игрок и так активен

## 6. БАЛАНС (BALANCE)

### Главная формула

```
Время_до_покупки = Стоимость / Доход_в_секунду
```

Должно быть:
- Первые 10 минут: 30-90 секунд
- 1 час: 2-5 минут
- 1 день: 5-15 минут
- 3 дня: 15-30 минут
- 7 дней: 30-60 минут (если поздний tier)

### Правило "золотого часа"

За первый час игрок должен:
- Открыть 5-7 уровней
- Заработать первый буст
- Заполнить коллекцию на 30%
- Получить 2-3 достижения
- Увидеть первый rewarded offer

### Magic Numbers из Merge Farm

```
Стартовый баланс:        100 монет
Стоимость первого слота: 500 монет
Стоимость 7-го слота:    25 000 монет
Множитель слотов:        ~1.5x

Стоимость boost 60:      ??? монет
Boost длительность:      30 минут
Boost множитель:         2x

Оффлайн %:               50%
Оффлайн max:             4 часа (14 400 сек)
Оффлайн cap:             3x от текущего дохода

Rare (golden):           2%
Mythic (rainbow):        0.5%
```

### Тестирование баланса

- Вручную пройти 1 час игры
- Сравнить со "золотым часом"
- Если что-то занимает > 5 минут — пересмотреть
- Если что-то занимает < 10 секунд — замедлить

## 7. PRESTIGE / PROGRESSION RESET

### Нужен ли

Только если:
- Поздняя игра (> 7 дней активного геймплея)
- Игрок может "устать" от текущего прогресса
- Есть что дать за сброс (уникальная валюта, бонус)

### Из Merge Farm

В v1.0 prestige нет. Это фича v2.0+.

### Когда добавлять

После успешного запуска, на основе retention-данных.

### Что НЕ делать

- ❌ Prestige в первые 7 дней
- ❌ Prestige без ясной выгоды
- ❌ Prestige, который ломает save
- ❌ Принудительный prestige

## 8. ЭКОНОМИКА КОНКРЕТНЫХ МЕХАНИК

### Merge (из Merge Farm)

```
Стоимость merge:    бесплатно
Награда за merge:   новый объект + N монет (зависит от уровня)
Новый объект:       следующий tier
```

### Кейсы (если есть)

```
Стоимость кейса:    100-1000 монет (зависит от tier)
Содержимое:         60% common, 30% rare, 9% epic, 1% legendary
Повтор:             шанс дубликата в оффере
```

### Буст

```
Тип:                x2 income на N минут
Стоимость:          N * 10 монет
Длительность:       5-60 минут
```

### Питомцы (если есть)

```
Стоимость покупки:   по питомцу
Доход:               +5-20% к income
Множитель:           суммируется, но с diminishing returns
```

## 9. САМОДИАГНОСТИКА

Перед релизом ответить на вопросы:

- [ ] Может ли игрок застрять без денег > 5 минут?
- [ ] Может ли игрок накопить слишком много за > 30 минут?
- [ ] Видны ли мезо-награды каждые 3-5 минут?
- [ ] Есть ли видимая цель на следующие 30 минут?
- [ ] Понятна ли формула цены игроку (визуально)?
- [ ] Нет ли двух валют без явной причины?
- [ ] Каждая награда что-то меняет?
- [ ] Sink'и работают (деньги не копятся бесконечно)?

Если хотя бы один ответ "нет" — пересмотреть.
