**Last Reviewed:** 2026-07-14

Версия: 1.0

## Что это

Сколько информации мозг игрока должен обработать одновременно.

Слишком много → игрок устаёт, уходит.
Слишком мало → скучно.

## Лимиты

```
Рабочая память:      4±1 элемента одновременно
Время на решение:    < 3 секунды для тактического
Время на стратегию:  < 30 секунд
```

## На экране одновременно

```
1 главное действие (большая кнопка по центру)
2-3 второстепенных (по краям)
0 чисто информационных (без действия)
```

Пример (Merge Farm):
```
Главное:       сетка 4x4 (центр)
Второстепенное: HUD вверху (монеты)
                Кнопка boost (правый низ)
                Кнопка menu (левый верх)
Информация:    подсказка (внизу, не мешает)
```

## Текст

Минимум. Если можно показать иконкой — показывай иконкой.

| Вместо текста | Иконка |
|---|---|
| Монеты | 💰 |
| Кристаллы | 💎 |
| Буст | ⚡ |
| Питомец | 🐶 |
| Настройки | ⚙️ |

## Меню

Не больше 5 опций в одном меню. Если больше — подменю.

```
Главное меню:
  - Играть (start/resume)
  - Питомцы
  - Настройки
  - Помощь

Подменю "Настройки":
  - Звук
  - Музыка
  - Язык
  - Сброс
```

## Модалки

Не блокировать игру, если не критично.

OK — модалки:
- Смена языка
- Покупка IAP
- Подтверждение сброса

НЕ OK — модалки:
- "Новый контент!" каждый день
- Rate us
- "Заходи завтра"
- Туториал (3+ окна подряд)

## Туториал

Если без него никак:
- 1 окно за раз, не цепочка
- Показывать с действием (не "нажми X", а "сделай X")
- Можно скипнуть
- Не повторять

## Анимации

- Длительность: 0.2-0.5 сек (микро), 0.5-1.0 сек (мезо)
- Не больше 2 одновременно
- Не блокировать ввод (если не требуется)

## Звук

- Не больше 3 одновременно
- Не зацикливать (выключать через 3 сек)
- Возможность отключить

## Тестирование

- Дать другу поиграть 5 минут
- Спросить: "Что тебе было непонятно?"
- Если > 2 момента — переделать
- Наблюдать: где он остановился и думал > 5 сек
