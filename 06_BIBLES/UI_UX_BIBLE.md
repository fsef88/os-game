## 1. ПРИНЦИПЫ

### Главное

Один экран = одна задача. Игрок не должен искать, куда нажать.

### Иерархия

```
1. Главное действие    — большое, по центру, яркое
2. Второстепенное      — по краям, среднее
3. Информация          — фон, мелкое
```

### Визуальный язык

| Цвет | Значение |
|---|---|
| Зелёный | Рост, плюс, хорошо |
| Красный | Опасность, минус, ошибка |
| Золотой | Редкость, ценность, награда |
| Фиолетовый | Магия, эпик, тайна |
| Синий | Информация, нейтрально |

Если цвет ничего не означает — не использовать.

## 2. LAYOUT

### Безопасные зоны (safe area)

```css
padding-top: env(safe-area-inset-top, 0);
padding-bottom: env(safe-area-inset-bottom, 0);
padding-left: env(safe-area-inset-left, 0);
padding-right: env(safe-area-inset-right, 0);
```

### Сетка

- 4x4 для merge
- 6x6 для clicker
- Адаптивная для tycoon

### Размер кнопок

- Главная: ≥ 88x88 px (тач-таргет)
- Второстепенная: ≥ 56x56 px
- Иконка: 44x44 px (минимум)

### Шрифты

- Главный: system-ui (быстро, знакомо)
- Числа: tabular-nums (не "прыгают" при изменении)
- Заголовки: bold
- Текст: regular, ≥ 14px

## 3. АНИМАЦИИ

### Цель анимации

Объяснять, не украшать.

| Действие | Анимация |
|---|---|
| Merge | Увеличение, свечение, fade out, fade in |
| Деньги | Летят в счётчик |
| Уровень вверх | Pulse + свечение |
| Ошибка | Тряска + красный flash |
| Награда | Bounce + частицы |

### Длительность

- Микро (0.2-0.3 сек): hover, click
- Мезо (0.3-0.7 сек): merge, spawn
- Макро (0.7-1.5 сек): level up, achievement
- Не больше 2 сек (игрок устаёт ждать)

### Принципы

- Easing: ease-out (для UI), ease-in-out (для объектов)
- Никогда linear (выглядит дёшево)
- Если не уверен — без анимации (лучше, чем плохая)

## 4. КНОПКИ

### Состояния

```
default    — обычное
hover      — наведение (desktop)
active     — нажата
disabled   — недоступна (серый + курсор not-allowed)
```

### Главная кнопка (CTA)

- Контрастный цвет
- Большой размер
- Текст ≤ 3 слова
- Всегда в одном месте на экране

### Второстепенные кнопки

- Outline style
- Меньший размер
- По краям

```

[Footer: 1-2 кнопки]
```

- Появление: scale 0.9 → 1.0 + fade
- Закрытие: scale 1.0 → 0.9 + fade
- Backdrop: fade in/out

### Dismiss

- Тап вне модалки (если не критичное)
- Кнопка X (всегда)
- Escape (desktop)
- Back gesture (mobile)

## 6. ЗВУК

### Главное

Звук — 50% опыта. Без звука игра ощущается "мёртвой".

### Каналы

```
sfx       — звуковые эффекты (UI, merge, spawn)
music     — фоновая музыка (опционально)
voice     — голос (редко)
```

### Громкость

- sfx: 0.6
- music: 0.3 (фон, не мешает)
- voice: 1.0

### Отключение

- Master toggle
- SFX toggle
- Music toggle
- Сохранять в state

### Когда НЕ играть звук

❌ В первые 3 секунды (игрок не ожидает)  
❌ Дольше 3 сек подряд  
❌ При таймере ожидания (напрягает)  
❌ Все каналы одновременно (хаос)

## 7. ИКОНКИ

### Размер

- 16x16 (в тексте)
- 24x24 (в кнопках)
- 44x44 (большие кнопки)
- 88x88 (hero)

### Стиль

- Один стиль (line OR fill, не mix)
- Один размер начертания
- Один цвет (или функциональный)

### Должны быть понятны без подписи

- 💰 Монеты
- ⚡ Буст
- 🎁 Кейс
- 🐶 Питомец
- ⚙️ Настройки

## 8. ОБРАТНАЯ СВЯЗЬ

### Каждое действие должно иметь feedback

- Click → ripple + звук
- Merge → анимация + звук + частицы
- Получена монета → +N летящий в счётчик
- Ошибка → shake + звук

### Время feedback

- Визуал: мгновенно (< 100ms)
- Звук: мгновенно
- Текст: через 200-500ms (не сразу)
- Действие: после подтверждения

### Отсутствие feedback = баг

Если игрок сделал действие, а ничего не произошло — он думает, что игра сломана.

## 9. ТЕКСТ

### Когда

- Заголовки (крупно)
- Числа (всегда)
- Подсказки (редко)

### Когда НЕТ

- Длинные описания
- Lore
- Туториал текстом
- Story

### Размеры

- Hero: 28-32px
- Title: 22-24px
- Body: 16-18px
- Caption: 12-14px

### Контраст

WCAG AA: ≥ 4.5:1 для текста
WCAG AAA: ≥ 7:1 для важного

## 10. ДОСТУПНОСТЬ (ACCESSIBILITY)

### Минимум

- Контрастный текст
- Tap-targets ≥ 44x44
- Возможность отключить звук
- Возможность отключить анимации (prefers-reduced-motion)

### Опционально

- Скринридеры (aria-labels)
- Управление с клавиатуры (desktop)
- Цветовая слепота (не только цвет, но и форма)
