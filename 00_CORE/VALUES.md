# Values
**Status:** Stable
**Owner:** Studio
**Version:** 1.4
**Last Reviewed:** 2026-07-14

---



1.

Player First.

Любое изменение должно приносить пользу игроку.

---

2.

Release beats Perfection.

Выпущенная игра лучше идеальной,
которая никогда не вышла.

---

3.

Simplicity.

Самое простое решение
обычно лучше самого красивого.

---

4.

Reuse.

Повторно использовать всё,
что уже работает.

---

5.

Documentation.

Документация важнее памяти модели.

---

6.

Experience.

Каждая игра обязана улучшить студию.
