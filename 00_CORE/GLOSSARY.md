Единые определения терминов. Использовать во всех документах Studio OS.

## Studio OS

**Studio OS** — операционная система студии. Документация, которая позволяет одному человеку + ИИ выпускать казуальные игры.

**Слой (Layer)** — категория документов с одинаковой ответственностью. Например: BIBLES, SYSTEMS, MECHANICS, COMPONENTS.

**Tier** — уровень приоритета. Tier S — обязательные, Tier A — желательные, Tier B — отложенные.

## Проект

**Жанр (Genre)** — что делает игрок. Merge, Clicker, Idle, Tycoon и т.д. См. `13_GENRES/`.

**Механика (Mechanic)** — переиспользуемая логика. Offline Progress, Quests, Daily Reward. См. `14_MECHANICS/`.

**Система (System)** — технический компонент. Save, Economy, UI, Audio. См. `15_SYSTEMS/`.

**Компонент (Component)** — UI-блок с готовым кодом. Button, Popup, HUD. См. `16_COMPONENTS/`.

**Bible** — глубокий справочник по теме. "Почему и какие принципы". См. `06_BIBLES/`.

**Reference** — базовые знания. См. `11_REFERENCE/`.

**Playbook** — пошаговый план действий для конкретного жанра или процесса. См. `05_PLAYBOOKS/`.

**ADR (Architecture Decision Record)** — зафиксированное архитектурное решение. См. `20_DECISIONS/`.

## Разработка

**MVP (Minimum Viable Product)** — минимальная версия игры, которую можно выпустить.

**Core Loop** — главный цикл геймплея. "Игрок делает X → получает Y".

**Meta Loop** — цикл поверх core loop. Уровни, коллекции, сезоны.

**Retention** — удержание игроков. D1, D7, D30 — процент вернувшихся.

**Churn** — отток игроков.

**LTV (Lifetime Value)** — доход с одного игрока за всю жизнь.

**ARPDAU (Average Revenue Per Daily Active User)** — средний доход на активного игрока в день.

**Onboarding** — первые 30 секунд игры. Tutorial + first impression.

**Balance** — баланс экономики и механик.

**Funnel** — воронка конверсии (увидел → установил → поиграл → остался).

## Игра

**Клетка (Cell)** — единица игрового поля. Merge-игра: 4x4 = 16 клеток.

**Tier** — уровень предмета. Tier 0 = семечко, Tier 10 = легендарный.

**Currency** — валюта. Soft (монеты), Hard (кристаллы).

**Pull (выпадение)** — случайное получение предмета.

**Pity (таймер)** — гарантированный drop после N попыток.

**Rewarded** — реклама за награду. Игрок смотрит добровольно.

**Interstitial** — полноэкранная реклама между сессиями.

**IAP (In-App Purchase)** — покупка за реальные деньги.

**Energy / Lives** — ограниченный ресурс (жизни в puzzle).

**Streak** — подряд дней входа.

**Prestige** — сброс прогресса за постоянный бонус.

**Rebirth** — мягкий prestige.

## Документы

**BIBLE** — отвечает на "почему" и "какие принципы". Пример: ECONOMY_BIBLE объясняет, какая экономика должна быть.

**SYSTEM** — отвечает на "как реализовано". Пример: ECONOMY_SYSTEM объясняет API класса EconomySystem.

**MECHANIC** — переиспользуемая игровая логика. Не зависит от жанра.

**GENRE** — спецификация для конкретного жанра. Зависит от набора механик.

**COMPONENT** — UI-блок с TypeScript кодом. Можно копировать в проект.

**DECISION** — зафиксированное решение с обоснованием.

**CASE STUDY** — разбор реального проекта (что сработало / нет).

**POSTMORTEM** — анализ после релиза.

**PATTERN** — проверенное решение, которое работает.

**ANTI-PATTERN** — типичная ошибка.

## Роли

**Producer** — решает "нужно ли", "стоит ли". Не пишет код.

**Architect** — структура проекта. Не пишет игровую логику.

**Game Designer** — Core Loop, Meta Loop, Retention. Не пишет код.

**Programmer** — реализует задачи. Не придумывает механики.

**QA** — ищет баги. Не исправляет.

**Art Director** — стиль, визуал. Не меняет логику.

**UX Designer** — пользовательский опыт. Не рисует.

**Balance Designer** — экономика, цены.

**Analytics** — метрики, события.

**Release Manager** — публикация, модерация.

**LiveOps** — обновления, события.

## Состояния

**F2P (Free-to-Play)** — игрок не платит деньгами.

**Payer** — игрок, покупающий IAP.

**DAU (Daily Active Users)** — уникальные игроки в день.

**WAU / MAU** — за неделю / месяц.

**Stickiness** — DAU/MAU. Как часто возвращается.

## Технические

**Cooldown** — минимальное время между действиями.

**Throttle** — ограничение частоты.

**Mock (SDK)** — заглушка для локальной разработки.

**Safe Area** — зона, не перекрываемая notch/island.

**DOM** — Document Object Model. HTML-дерево.

**SVG** — масштабируемая векторная графика.

**Bundle** — итоговый JS+CSS+HTML после сборки.

**HMR (Hot Module Replacement)** — мгновенное обновление без перезагрузки.
