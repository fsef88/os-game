# Case 01 — почему выбран clicker

Clicker выбран как первый пилот, потому что он минимально нагружает систему и быстро показывает, где template реально помогает, а где только обещает помочь.

## Вывод

Для первого контрольного цикла clicker лучше merge, потому что:
- меньше UI-сложности;
- не нужен drag/drop;
- проще тестировать build pipeline;
- быстрее получить playable result.
