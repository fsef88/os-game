# BlackHole

Toy-first arcade pilot for Studio OS.

Связанный проект:
- `../../90_PROJECTS/BlackHole/`

## Что проверяет
- может ли Studio OS родить прототип, который считывается как игра с первого взгляда;
- работает ли one-screen arcade loop лучше, чем интерфейсно-тяжёлые концепты;
- насколько хорошо для браузера работает fantasy роста через поглощение.
