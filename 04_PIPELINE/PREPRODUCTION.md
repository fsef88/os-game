# Project Start

Для нового проекта
необходимо заполнить

PROJECT_TEMPLATE

MISSION

ROADMAP

CURRENT_SPRINT

NEXT_TASK

Только после этого
начинается разработка.


---

# One Week Rule

Новая игра
должна помещаться
в 7–10 дней.

Если нет —

уменьшить объём.

Не увеличивать сроки.

Лучше выпустить
две хорошие игры,
чем одну идеальную.
