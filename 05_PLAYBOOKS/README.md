# 05_PLAYBOOKS

**Версия:** 1.0  
**Дата:** 2026-07-14

---

Playbook — это **короткий пошаговый маршрут** для конкретного жанра или процесса.

## Жанровые playbook'и

- `BUILD_MERGE.md`
- `BUILD_CLICKER.md`
- `BUILD_IDLE.md`
- `BUILD_TYCOON.md`
- `BUILD_PUZZLE.md`

## Процессные playbook'и

- `QA_PLAYBOOK.md`
- `RELEASE_PLAYBOOK.md`

## Как использовать

1. Выбрать жанр
2. Скопировать `90_PROJECTS/TEMPLATE/`
3. Открыть нужный playbook
4. Идти по дням, а не по вдохновению
